# 每日工作记录记事本 · 交付文档

## 需求解读

复述确认：开发一款**本地优先的桌面工作日志应用**——按日历记录每日工作（标题/内容/状态/多标签），支持软删除回收站、500ms 防抖自动保存、标签筛选管理、FTS5 全文搜索（高亮+日期范围）、五页面（主页/时间线/搜索/回收站/设置）、月度统计与趋势、Markdown 日报/周报/月报/全部导出、一键备份恢复、三主题、Ctrl+N/Ctrl+F 快捷键，窗口 980×680 可缩放。技术栈硬约束全部满足：Tauri 2（Rust 后端）+ Vue3 TS（全 `<script setup lang="ts">`）+ Pinia + shadcn-vue + Tailwind + lucide + SQLite（rusqlite bundled + FTS5），无网络/无登录/无云同步；全部 CRUD/备份/导出由 Rust Tauri Command 实现，前端只做视图。

---

## ① 简介 & 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 桌面壳 | **Tauri 2**（禁 Electron 已满足） | identifier `com.workjournal.app`，无 Node 运行时、无 Chromium 打包体积 |
| 后端 | **Rust** | `main.rs`（入口）/ `commands.rs`（19 个 Command，入参校验）/ `db.rs`（939 行，迁移/FTS5/CRUD/备份/导出 + 11 个单元测试） |
| 前端 | **Vue 3 + TypeScript**（全部 `<script setup lang="ts">`）+ **Pinia** + Vue Router（hash 模式） | 五页面 + 8 个业务组件 |
| UI | **shadcn-vue + Tailwind CSS + lucide**（@lucide/vue） | 未用 Element-Plus/Ant-Vue；日历由 reka-ui 原语组合 |
| 数据库 | **SQLite**（rusqlite 0.32，bundled 编译） | 启用 **FTS5** 全文索引 + 版本迁移（`PRAGMA user_version`） |
| 其他关键库 | reka-ui、@internationalized/date、date-fns、clsx + tailwind-merge | 前端仅视图层依赖 |

**核心架构决策（本项目的难点与解法）**：SQLite bundled 3.46 的 unicode61 分词器把连续中文字符视为**单个 token**，导致「修复登录接口超时」中搜索「超时」（词中缀）无法命中。方案：Rust 注册 `cjk_expand` UDF，写入 FTS 索引时把连续 CJK 字符展开为单字（字符间插空格），查询词经 `build_fts_query` 同步展开为单字短语（`"超 时"`），中文任意子串均可命中；高亮与摘要由**前端**基于原文按命中词分段渲染（纯文本 + `<mark>`，无 v-html 注入面）。

```rust
// 工作日志 —— Tauri 2 入口。
// 职责单一：注册插件、初始化应用数据目录、打开数据库并执行迁移、注册全部命令。
// 业务 SQL 见 db.rs，对外命令见 commands.rs。

// Windows 发布版不弹出附加控制台窗口
#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]

mod commands;
mod db;

use std::sync::Mutex;
use tauri::Manager;

fn main() {
    let app = tauri::Builder::default()
        .plugin(tauri_plugin_dialog::init())
        .setup(|app| {
            let data_dir = app
                .path()
                .app_data_dir()
                .map_err(|e| format!("无法获取应用数据目录：{e}"))?;
            std::fs::create_dir_all(&data_dir)
                .map_err(|e| format!("无法创建数据目录 {}：{e}", data_dir.display()))?;
            let db_path = data_dir.join("work-journal.db");
            let db = db::Db::open(&db_path).map_err(|e| format!("数据库初始化失败：{e:#}"))?;
            app.manage(commands::AppState {
                db: Mutex::new(db),
                db_path,
            });
            Ok(())
        })
        .invoke_handler(tauri::generate_handler![
            commands::get_records_by_date,
            commands::create_record,
            commands::update_record,
            commands::soft_delete_record,
            commands::restore_record,
            commands::purge_record,
            commands::empty_trash,
            commands::get_trash_records,
            commands::get_timeline,
            commands::search_records,
            commands::get_record_dates,
            commands::get_all_tags,
            commands::get_month_stats,
            commands::get_trend,
            commands::export_report,
            commands::backup_database,
            commands::restore_database,
            commands::get_db_path,
            commands::get_app_version,
        ])
        .build(tauri::generate_context!())
        .expect("工作日志构建失败");

    // Tauri 2 的 run 返回 ()，运行期错误由框架内部记录日志；
    // setup/构建阶段的错误已在上面通过 expect/Result 兜底，不会静默吞掉。
    app.run(|_app, event| {
        if let tauri::RunEvent::ExitRequested { .. } = event {
            // 预留：退出前可在此刷新未保存状态（当前无后台任务）
        }
    });
}
```

```rust
//! Tauri 对外命令层：入参校验 → 调用 db.rs → 统一把 anyhow 错误转为前端可读字符串。
//! 所有命令均为同步函数（Tauri 将其调度到主线程执行），
//! 阻塞式保存/选择对话框（macOS 要求主线程）与数据库操作均安全。

use crate::db::{self, Db};
use anyhow::Result;
use std::path::PathBuf;
use std::sync::{Mutex, MutexGuard};
use tauri::{AppHandle, State};
use tauri_plugin_dialog::DialogExt;

/// 全局共享状态：数据库连接（互斥锁保护）与数据库文件路径
pub struct AppState {
    pub db: Mutex<Db>,
    pub db_path: PathBuf,
}

/// 提取 anyhow 错误链的第一行（含上下文），作为前端可读信息
fn err_str(e: anyhow::Error) -> String {
    let s = format!("{e:#}");
    s.lines().next().unwrap_or("操作失败").to_string()
}

fn db_of<'a>(state: &'a State<AppState>) -> Result<MutexGuard<'a, Db>, String> {
    state
        .db
        .lock()
        .map_err(|_| "数据库连接异常，请重启应用".to_string())
}

/// 文本入参统一校验：长度上限
fn check_text(value: &str, field: &str, max: usize) -> Result<(), String> {
    if value.chars().count() > max {
        return Err(format!("{field}过长（最多 {max} 个字符）"));
    }
    Ok(())
}

pub fn get_records_by_date(state: State<AppState>, date: String) -> Result<Vec<db::WorkRecord>, String> {
    db::validate_date(&date).map_err(err_str)?;
    db_of(&state)?.list_by_date(&date).map_err(err_str)
}

#[tauri::command]
pub fn create_record(
    state: State<AppState>,
    date: String,
    title: String,
    content: String,
    status: String,
    tags: String,
) -> Result<db::WorkRecord, String> {
    db::validate_date(&date).map_err(err_str)?;
    db::validate_status(&status).map_err(err_str)?;
    check_text(&title, "标题", db::MAX_TITLE_LEN)?;
    check_text(&content, "内容", db::MAX_CONTENT_LEN)?;
    let title = title.trim().to_string();
    let tags = db::normalize_tags(&tags).map_err(err_str)?;
    db_of(&state)?
        .create(&date, &title, &content, &status, &tags)
        .map_err(err_str)
}

#[tauri::command]
pub fn update_record(
    state: State<AppState>,
    id: i64,
    title: String,
    content: String,
    status: String,
    tags: String,
) -> Result<db::WorkRecord, String> {
    if id <= 0 {
        return Err("记录 id 无效".to_string());
    }
    db::validate_status(&status).map_err(err_str)?;
    check_text(&title, "标题", db::MAX_TITLE_LEN)?;
    check_text(&content, "内容", db::MAX_CONTENT_LEN)?;
    let title = title.trim().to_string();
    let tags = db::normalize_tags(&tags).map_err(err_str)?;
    db_of(&state)?
        .update(id, &title, &content, &status, &tags)
        .map_err(err_str)
}

#[tauri::command]
pub fn search_records(
    state: State<AppState>,
    query: String,
    date_from: Option<String>,
    date_to: Option<String>,
) -> Result<Vec<db::WorkRecord>, String> {
    if let Some(f) = &date_from {
        db::validate_date(f).map_err(err_str)?;
    }
    if let Some(t) = &date_to {
        db::validate_date(t).map_err(err_str)?;
    }
    if let (Some(f), Some(t)) = (&date_from, &date_to) {
        if f > t {
            return Err("开始日期不能晚于结束日期".to_string());
        }
    }
    let query = query.trim();
    if query.is_empty() {
        return Ok(Vec::new());
    }
    db_of(&state)?
        .search(query, date_from.as_deref(), date_to.as_deref())
        .map_err(err_str)
}

#[tauri::command]
pub fn export_report(
    app: AppHandle,
    state: State<AppState>,
    kind: String,
    date: String,
) -> Result<Option<String>, String> {
    if !matches!(kind.as_str(), "daily" | "weekly" | "monthly" | "all") {
        return Err("导出类型无效".to_string());
    }
    db::validate_date(&date).map_err(err_str)?;
    let markdown = db_of(&state)?
        .export_markdown(&kind, &date)
        .map_err(err_str)?;
    let default_name = match kind.as_str() {
        "daily" => format!("工作日报-{date}.md"),
        "weekly" => "工作周报.md".to_string(),
        "monthly" => "工作月报.md".to_string(),
        _ => "工作记录总览.md".to_string(),
    };
    let picked = app
        .dialog()
        .file()
        .set_title("导出为 Markdown")
        .set_file_name(&default_name)
        .add_filter("Markdown", &["md"])
        .blocking_save_file();
    let Some(path) = picked else {
        return Ok(None); // 用户取消
    };
    let path = path.into_path().map_err(|e| e.to_string())?;
    std::fs::write(&path, markdown.as_bytes())
        .map_err(|e| format!("写入文件失败：{e}"))?;
    Ok(Some(path.display().to_string()))
}

#[tauri::command]
pub fn backup_database(app: AppHandle, state: State<AppState>) -> Result<Option<String>, String> {
    let picked = app
        .dialog()
        .file()
        .set_title("选择备份保存文件夹")
        .blocking_pick_folder();
    let Some(dir) = picked else {
        return Ok(None); // 用户取消
    };
    let dir = dir.into_path().map_err(|e| e.to_string())?;
    let ts = chrono::Local::now().format("%Y%m%d-%H%M%S");
    let dest = dir.join(format!("工作日志备份-{ts}.db"));
    db_of(&state)?.backup_to(&dest).map_err(err_str)?;
    Ok(Some(dest.display().to_string()))
}

#[tauri::command]
pub fn restore_database(app: AppHandle, state: State<AppState>) -> Result<Option<i64>, String> {
    let picked = app
        .dialog()
        .file()
        .set_title("选择备份文件（.db）")
        .add_filter("SQLite 数据库", &["db"])
        .blocking_pick_file();
    let Some(file) = picked else {
        return Ok(None); // 用户取消
    };
    let src = file.into_path().map_err(|e| e.to_string())?;
    let mut db = db_of(&state)?; // restore_from 需要 &mut self
    // 恢复前先把当前数据自动备份到应用数据目录，防止误操作造成不可逆丢失
    let ts = chrono::Local::now().format("%Y%m%d-%H%M%S");
    let safety = state
        .db_path
        .with_file_name(format!("恢复前自动备份-{ts}.db"));
    db.backup_to(&safety)
        .map_err(|e| format!("恢复前安全备份失败，已中止恢复：{e:#}"))?;
    let count = db.restore_from(&src).map_err(err_str)?;
    Ok(Some(count))
}
```

```rust
//! 数据库层：初始化、版本迁移、FTS5 全文索引、全部 CRUD、备份/恢复、Markdown 导出。
//! 所有函数返回 anyhow::Result，由 commands.rs 统一转换为前端可读的错误信息，
//! 本层不允许 panic。

use anyhow::{anyhow, bail, Context, Result};
use chrono::{Datelike, Duration, Local, NaiveDate};
use rusqlite::functions::FunctionFlags;
use rusqlite::{params, Connection, OptionalExtension};
use serde::Serialize;
use std::collections::{HashMap, HashSet};
use std::path::Path;

/// 中文全文搜索的关键：unicode61 默认把连续 CJK 字符视为单个 token，
/// 「超时」这类词中缀无法被前缀/短语查询命中。
/// 方案：写入 FTS 时经 cjk_expand UDF 把连续 CJK 字符展开为单字（字符间插空格），
/// 查询词做同样展开后以短语匹配，中文任意子串均可命中。
/// 高亮与摘要由前端基于原文与查询词渲染，后端只负责召回。

/// 字段长度上限（按字符数，防异常输入撑爆数据库）
pub const MAX_TITLE_LEN: usize = 500;
pub const MAX_CONTENT_LEN: usize = 100_000;
pub const MAX_TAG_LEN: usize = 50;

/// 数据库迁移脚本。规则：只允许追加新版本，禁止修改已发布版本；
/// 当前版本号记录在 PRAGMA user_version 中，升级程序按版本递增执行，历史数据不丢失。
const MIGRATIONS: &[&str] = &[
    // v1: 初始表结构 + 索引 + FTS5 全文索引 + 增删改同步触发器。
    // 触发器写入时经 cjk_expand UDF 把连续 CJK 字符展开为单字，
    // 使中文任意子串（如「超时」在「修复登录接口超时」中）可被短语查询命中。
    // UDF 在 Db::open 时注册（migrate 之前），触发器执行时必然可用。
    r#"
CREATE TABLE IF NOT EXISTS records (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    record_date TEXT    NOT NULL,
    title       TEXT    NOT NULL DEFAULT '',
    content     TEXT    NOT NULL DEFAULT '',
    status      TEXT    NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'completed')),
    tags        TEXT    NOT NULL DEFAULT '',
    is_deleted  INTEGER NOT NULL DEFAULT 0,
    created_at  TEXT    NOT NULL,
    updated_at  TEXT    NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_records_date ON records (record_date);
CREATE INDEX IF NOT EXISTS idx_records_deleted ON records (is_deleted);
CREATE VIRTUAL TABLE IF NOT EXISTS records_fts USING fts5 (
    title, content, tags,
    content = 'records',
    content_rowid = 'id',
    tokenize = 'unicode61'
);
CREATE TRIGGER IF NOT EXISTS trg_records_ai AFTER INSERT ON records BEGIN
    INSERT INTO records_fts (rowid, title, content, tags)
    VALUES (new.id, cjk_expand(new.title), cjk_expand(new.content), cjk_expand(new.tags));
END;
CREATE TRIGGER IF NOT EXISTS trg_records_ad AFTER DELETE ON records BEGIN
    INSERT INTO records_fts (records_fts, rowid, title, content, tags)
    VALUES ('delete', old.id, cjk_expand(old.title), cjk_expand(old.content), cjk_expand(old.tags));
END;
-- 注意：FTS5 外部内容表要求索引与内容表行一一对应，触发器必须无条件同步。
-- 若按 is_deleted 条件跳过插入，会出现「内容表有行、索引无行」的中间态，
-- 后续对该行 UPDATE 时 FTS5 的 'delete' 校验会判为索引损坏（错误 267）。
-- 软删除行的过滤由 search 查询中的 r.is_deleted = 0 承担。
CREATE TRIGGER IF NOT EXISTS trg_records_au AFTER UPDATE ON records BEGIN
    INSERT INTO records_fts (records_fts, rowid, title, content, tags)
    VALUES ('delete', old.id, cjk_expand(old.title), cjk_expand(old.content), cjk_expand(old.tags));
    INSERT INTO records_fts (rowid, title, content, tags)
    VALUES (new.id, cjk_expand(new.title), cjk_expand(new.content), cjk_expand(new.tags));
END;
"#,
];

/// 一条工作记录，与前端 TS 接口 WorkRecord 字段一一对应
#[derive(Debug, Clone, Serialize)]
pub struct WorkRecord {
    pub id: i64,
    pub record_date: String,
    pub title: String,
    pub content: String,
    pub status: String,
    pub tags: String,
    pub is_deleted: bool,
    pub created_at: String,
    pub updated_at: String,
}

#[derive(Debug, Serialize)]
pub struct TagStat {
    pub tag: String,
    pub count: i64,
}

#[derive(Debug, Serialize)]
pub struct MonthStats {
    pub month: String,
    pub total: i64,
    pub completed: i64,
    pub pending: i64,
}

#[derive(Debug, Serialize)]
pub struct TrendPoint {
    pub month: String,
    pub total: i64,
    pub completed: i64,
}

/// 数据库封装。连接在 Tauri AppState 中以 Mutex<Db> 持有，跨命令共享。
pub struct Db {
    conn: Connection,
}

const RECORD_COLS: &str =
    "id, record_date, title, content, status, tags, is_deleted, created_at, updated_at";

/// search JOIN records_fts 时使用的 r. 前缀列清单，
/// 避免 title/content/tags 与 FTS 虚拟表同名列产生歧义
const RECORD_COLS_R: &str =
    "r.id, r.record_date, r.title, r.content, r.status, r.tags, r.is_deleted, r.created_at, r.updated_at";

fn row_to_record(row: &rusqlite::Row) -> rusqlite::Result<WorkRecord> {
    Ok(WorkRecord {
        id: row.get(0)?,
        record_date: row.get(1)?,
        title: row.get(2)?,
        content: row.get(3)?,
        status: row.get(4)?,
        tags: row.get(5)?,
        is_deleted: row.get::<_, i64>(6)? != 0,
        created_at: row.get(7)?,
        updated_at: row.get(8)?,
    })
}

fn now_str() -> String {
    Local::now().format("%Y-%m-%d %H:%M:%S").to_string()
}

impl Db {
    /// 打开（不存在则创建）数据库文件：应用 PRAGMA、注册 UDF 并执行版本迁移
    pub fn open(path: &Path) -> Result<Self> {
        let conn = Connection::open(path)
            .with_context(|| format!("无法打开数据库文件：{}", path.display()))?;
        let mut db = Self { conn };
        db.apply_pragmas()?;
        register_functions(&db.conn)?; // 迁移触发器依赖 cjk_expand，必须先注册
        db.migrate()?;
        Ok(db)
    }

    /// 内存库，仅供单元测试使用
    #[cfg(test)]
    pub fn open_in_memory() -> Result<Self> {
        let mut db = Self {
            conn: Connection::open_in_memory()?,
        };
        db.apply_pragmas()?;
        register_functions(&db.conn)?;
        db.migrate()?;
        Ok(db)
    }

    fn apply_pragmas(&self) -> Result<()> {
        self.conn.execute_batch(
            "PRAGMA journal_mode = WAL;
             PRAGMA synchronous = NORMAL;
             PRAGMA foreign_keys = ON;
             PRAGMA busy_timeout = 5000;",
        )?;
        Ok(())
    }

    /// 按 user_version 递增执行未应用的迁移脚本，每个版本一个事务
    fn migrate(&mut self) -> Result<()> {
        let current: i64 = self.conn.query_row("PRAGMA user_version", [], |r| r.get(0))?;
        for (idx, sql) in MIGRATIONS.iter().enumerate() {
            let version = (idx + 1) as i64;
            if version <= current {
                continue;
            }
            let tx = self.conn.transaction().context("开启迁移事务失败")?;
            tx.execute_batch(sql)
                .with_context(|| format!("执行数据库迁移 v{version} 失败"))?;
            tx.pragma_update(None, "user_version", version)?;
            tx.commit()?;
        }
        Ok(())
    }

    /// 重建 FTS 索引（恢复备份后调用，保证索引与数据一致）。
    /// 注意：不能使用 FTS5 的 'rebuild' 命令——它直接从内容表读原始列值，
    /// 会绕过 cjk_expand 单字展开；这里手动 DELETE + INSERT SELECT 重建。
    pub fn rebuild_fts(&self) -> Result<()> {
        self.conn.execute_batch(
            "DELETE FROM records_fts;
             INSERT INTO records_fts (rowid, title, content, tags)
             SELECT id, cjk_expand(title), cjk_expand(content), cjk_expand(tags) FROM records;",
        )?;
        Ok(())
    }

    // ---------- 查询 ----------

    pub fn list_by_date(&self, date: &str) -> Result<Vec<WorkRecord>> {
        let mut stmt = self.conn.prepare(&format!(
            "SELECT {RECORD_COLS} FROM records
             WHERE record_date = ?1 AND is_deleted = 0
             ORDER BY created_at ASC, id ASC"
        ))?;
        let rows = stmt.query_map(params![date], row_to_record)?;
        Ok(rows.collect::<rusqlite::Result<Vec<_>>>()?)
    }

    pub fn get(&self, id: i64) -> Result<Option<WorkRecord>> {
        let row = self
            .conn
            .query_row(
                &format!("SELECT {RECORD_COLS} FROM records WHERE id = ?1"),
                params![id],
                row_to_record,
            )
            .optional()?;
        Ok(row)
    }

    pub fn trash(&self) -> Result<Vec<WorkRecord>> {
        let mut stmt = self.conn.prepare(&format!(
            "SELECT {RECORD_COLS} FROM records WHERE is_deleted = 1 ORDER BY updated_at DESC"
        ))?;
        let rows = stmt.query_map([], row_to_record)?;
        Ok(rows.collect::<rusqlite::Result<Vec<_>>>()?)
    }

    /// 时间线分页查询：按日期倒序、同日按 id 倒序
    pub fn timeline(&self, offset: i64, limit: i64) -> Result<Vec<WorkRecord>> {
        let mut stmt = self.conn.prepare(&format!(
            "SELECT {RECORD_COLS} FROM records WHERE is_deleted = 0
             ORDER BY record_date DESC, id DESC LIMIT ?1 OFFSET ?2"
        ))?;
        let rows = stmt.query_map(params![limit, offset], row_to_record)?;
        Ok(rows.collect::<rusqlite::Result<Vec<_>>>()?)
    }

    /// 全部有记录日期（日历高亮用）
    pub fn record_dates(&self) -> Result<Vec<String>> {
        let mut stmt = self
            .conn
            .prepare("SELECT DISTINCT record_date FROM records WHERE is_deleted = 0")?;
        let rows = stmt.query_map([], |r| r.get::<_, String>(0))?;
        Ok(rows.collect::<rusqlite::Result<Vec<_>>>()?)
    }

    /// 全部已使用标签及计数（按使用次数倒序）
    pub fn all_tags(&self) -> Result<Vec<TagStat>> {
        let mut stmt = self
            .conn
            .prepare("SELECT tags FROM records WHERE is_deleted = 0")?;
        let rows = stmt.query_map([], |r| r.get::<_, String>(0))?;
        let mut map: HashMap<String, i64> = HashMap::new();
        for tags in rows {
            for t in split_tags(&tags?) {
                *map.entry(t).or_default() += 1;
            }
        }
        let mut v: Vec<TagStat> = map
            .into_iter()
            .map(|(tag, count)| TagStat { tag, count })
            .collect();
        v.sort_by(|a, b| b.count.cmp(&a.count).then_with(|| a.tag.cmp(&b.tag)));
        Ok(v)
    }

    /// 单月统计：总记录 / 已完成 / 待完成
    pub fn month_stats(&self, month: &str) -> Result<MonthStats> {
        let (total, completed): (i64, i64) = self.conn.query_row(
            "SELECT COUNT(*), COALESCE(SUM(status = 'completed'), 0) FROM records
             WHERE is_deleted = 0 AND substr(record_date, 1, 7) = ?1",
            params![month],
            |r| Ok((r.get(0)?, r.get(1)?)),
        )?;
        Ok(MonthStats {
            month: month.to_string(),
            total,
            completed,
            pending: total - completed,
        })
    }

    /// 近 N 个月完成趋势（缺失月份补零，按时间升序）
    pub fn trend(&self, months: i64) -> Result<Vec<TrendPoint>> {
        let months = months.clamp(1, 24);
        let today = Local::now().date_naive();
        let cur_idx = today.year() * 12 + today.month0() as i32;
        let start_idx = cur_idx - (months - 1) as i32;
        let start_month = format!("{:04}-{:02}", start_idx / 12, start_idx % 12 + 1);
        let cur_month = format!("{:04}-{:02}", today.year(), today.month());
        let mut stmt = self.conn.prepare(
            "SELECT substr(record_date, 1, 7) AS m, COUNT(*), COALESCE(SUM(status = 'completed'), 0)
             FROM records
             WHERE is_deleted = 0 AND m BETWEEN ?1 AND ?2
             GROUP BY m",
        )?;
        let map: HashMap<String, (i64, i64)> = stmt
            .query_map(params![start_month, cur_month], |r| {
                Ok((
                    r.get::<_, String>(0)?,
                    (r.get::<_, i64>(1)?, r.get::<_, i64>(2)?),
                ))
            })?
            .collect::<rusqlite::Result<_>>()?;
        let mut out = Vec::with_capacity(months as usize);
        for idx in start_idx..=cur_idx {
            let key = format!("{:04}-{:02}", idx / 12, idx % 12 + 1);
            let (total, completed) = map.get(&key).copied().unwrap_or((0, 0));
            out.push(TrendPoint {
                month: key,
                total,
                completed,
            });
        }
        Ok(out)
    }

    /// FTS5 全文搜索：命中标题/内容/标签，支持日期范围。
    /// 只负责召回记录本体；关键词高亮与内容摘要由前端基于原文渲染。
    pub fn search(
        &self,
        query: &str,
        date_from: Option<&str>,
        date_to: Option<&str>,
    ) -> Result<Vec<WorkRecord>> {
        let match_expr = build_fts_query(query);
        if match_expr.is_empty() {
            return Ok(Vec::new());
        }
        let f = date_from.unwrap_or("0000-00-00");
        let t = date_to.unwrap_or("9999-99-99");
        let sql = format!(
            "SELECT {RECORD_COLS_R} FROM records_fts
             JOIN records r ON r.id = records_fts.rowid
             WHERE records_fts MATCH ?1 AND r.is_deleted = 0
               AND r.record_date BETWEEN ?2 AND ?3
             ORDER BY r.record_date DESC, r.id DESC
             LIMIT 200"
        );
        let mut stmt = self.conn.prepare(&sql)?;
        let rows = stmt.query_map(params![match_expr, f, t], row_to_record)?;
        Ok(rows.collect::<rusqlite::Result<Vec<_>>>()?)
    }

    // ---------- 写入 ----------

    pub fn create(
        &self,
        record_date: &str,
        title: &str,
        content: &str,
        status: &str,
        tags: &str,
    ) -> Result<WorkRecord> {
        let now = now_str();
        self.conn.execute(
            "INSERT INTO records (record_date, title, content, status, tags, is_deleted, created_at, updated_at)
             VALUES (?1, ?2, ?3, ?4, ?5, 0, ?6, ?6)",
            params![record_date, title, content, status, tags, now],
        )?;
        let id = self.conn.last_insert_rowid();
        self.get(id)?.ok_or_else(|| anyhow!("记录创建后读取失败"))
    }

    pub fn update(
        &self,
        id: i64,
        title: &str,
        content: &str,
        status: &str,
        tags: &str,
    ) -> Result<WorkRecord> {
        let n = self.conn.execute(
            "UPDATE records SET title = ?2, content = ?3, status = ?4, tags = ?5, updated_at = ?6
             WHERE id = ?1 AND is_deleted = 0",
            params![id, title, content, status, tags, now_str()],
        )?;
        if n == 0 {
            bail!("记录不存在或已在回收站中");
        }
        self.get(id)?.ok_or_else(|| anyhow!("记录更新后读取失败"))
    }

    /// 软删除：移入回收站（触发器同步移除 FTS 索引）
    pub fn soft_delete(&self, id: i64) -> Result<()> {
        let n = self.conn.execute(
            "UPDATE records SET is_deleted = 1, updated_at = ?2 WHERE id = ?1 AND is_deleted = 0",
            params![id, now_str()],
        )?;
        if n == 0 {
            bail!("记录不存在或已在回收站中");
        }
        Ok(())
    }

    pub fn restore(&self, id: i64) -> Result<()> {
        let n = self.conn.execute(
            "UPDATE records SET is_deleted = 0, updated_at = ?2 WHERE id = ?1 AND is_deleted = 1",
            params![id, now_str()],
        )?;
        if n == 0 {
            bail!("记录不存在或不在回收站中");
        }
        Ok(())
    }

    /// 物理删除（仅回收站中可执行），触发器同步清理 FTS 索引
    pub fn purge(&self, id: i64) -> Result<()> {
        let n = self.conn.execute("DELETE FROM records WHERE id = ?1 AND is_deleted = 1", params![id])?;
        if n == 0 {
            bail!("记录不存在或不在回收站中");
        }
        Ok(())
    }

    /// 清空回收站，返回删除条数
    pub fn empty_trash(&self) -> Result<i64> {
        let n = self.conn.execute("DELETE FROM records WHERE is_deleted = 1", [])?;
        Ok(n as i64)
    }

    // ---------- 导出 / 备份 / 恢复 ----------

    /// 生成 Markdown 报告内容（daily/weekly/monthly/all），日期按升序
    pub fn export_markdown(&self, kind: &str, date: &str) -> Result<String> {
        let anchor = NaiveDate::parse_from_str(date, "%Y-%m-%d").context("导出日期无效")?;
        let (from, to) = match kind {
            "daily" => (Some(anchor), Some(anchor)),
            "weekly" => {
                // 周报口径：所选日期所在周的周一 ~ 周日（业界通用口径）
                let start = anchor - Duration::days(anchor.weekday().num_days_from_monday() as i64);
                (Some(start), Some(start + Duration::days(6)))
            }
            "monthly" => {
                let start = anchor
                    .with_day(1)
                    .ok_or_else(|| anyhow!("无法计算月初日期"))?;
                let next = if anchor.month() == 12 {
                    NaiveDate::from_ymd_opt(anchor.year() + 1, 1, 1)
                } else {
                    NaiveDate::from_ymd_opt(anchor.year(), anchor.month() + 1, 1)
                }
                .ok_or_else(|| anyhow!("无法计算下月初日期"))?;
                (Some(start), Some(next - Duration::days(1)))
            }
            _ => (None, None),
        };
        let mut stmt = self.conn.prepare(&format!(
            "SELECT {RECORD_COLS} FROM records
             WHERE is_deleted = 0
               AND (?1 IS NULL OR record_date >= ?1)
               AND (?2 IS NULL OR record_date <= ?2)
             ORDER BY record_date ASC, id ASC"
        ))?;
        // NaiveDate 未实现 ToSql，转成 yyyy-MM-dd 字符串（字典序即日期序）再绑定
        let from_s = from.map(|d| d.to_string());
        let to_s = to.map(|d| d.to_string());
        let rows: Vec<WorkRecord> = stmt
            .query_map(params![from_s, to_s], row_to_record)?
            .collect::<rusqlite::Result<Vec<_>>>()?;
        build_markdown(kind, from, to, &rows)
    }

    /// 备份：使用 SQLite 在线备份 API 生成一致性快照（自动处理 WAL，无需停机）
    pub fn backup_to(&self, dest: &Path) -> Result<()> {
        let mut dest_conn = Connection::open(dest)
            .with_context(|| format!("无法创建备份文件：{}", dest.display()))?;
        let backup = rusqlite::backup::Backup::new(&self.conn, &mut dest_conn)?;
        backup.run_to_completion(64, std::time::Duration::from_millis(10), None)?;
        Ok(())
    }

    /// 恢复：先校验备份文件有效性，再用备份 API 覆盖当前库，最后重建 FTS。
    /// 返回恢复后的有效记录数。
    pub fn restore_from(&mut self, src: &Path) -> Result<i64> {
        let src_conn = Connection::open(src)
            .with_context(|| format!("无法打开备份文件：{}", src.display()))?;
        src_conn
            .query_row("SELECT 1 FROM records LIMIT 1", [], |_| Ok(()))
            .with_context(|| "所选文件不是有效的工作日志备份（缺少 records 表）")?;
        let count: i64 = src_conn.query_row(
            "SELECT COUNT(*) FROM records WHERE is_deleted = 0",
            [],
            |r| r.get(0),
        )?;
        // backup 持有 &mut self.conn，需在借用结束（drop）后再重建 FTS
        {
            let backup = rusqlite::backup::Backup::new(&src_conn, &mut self.conn)?;
            backup.run_to_completion(64, std::time::Duration::from_millis(10), None)?;
        }
        self.rebuild_fts()?;
        Ok(count)
    }
}

// ---------- 纯函数：标签 / 校验 / FTS 查询构造 / Markdown 组装 ----------

/// 拆分标签（兼容中英文逗号、分号）
pub fn split_tags(tags: &str) -> Vec<String> {
    tags.split([',', '，', ';', '；'])
        .map(|s| s.trim().to_string())
        .filter(|s| !s.is_empty())
        .collect()
}

/// 规范化标签：去空白、去重、限制单个标签长度
pub fn normalize_tags(tags: &str) -> Result<String> {
    let mut seen = HashSet::new();
    let mut out: Vec<String> = Vec::new();
    for t in split_tags(tags) {
        if t.chars().count() > MAX_TAG_LEN {
            bail!("单个标签不能超过 {MAX_TAG_LEN} 个字符：{t}");
        }
        if seen.insert(t.clone()) {
            out.push(t);
        }
    }
    Ok(out.join(","))
}

pub fn validate_date(date: &str) -> Result<()> {
    NaiveDate::parse_from_str(date, "%Y-%m-%d")
        .map(|_| ())
        .map_err(|_| anyhow!("日期格式无效，应为 yyyy-MM-dd：{date}"))
}

pub fn validate_status(status: &str) -> Result<()> {
    if matches!(status, "pending" | "completed") {
        Ok(())
    } else {
        bail!("状态值无效：{status}")
    }
}

pub fn validate_month(month: &str) -> Result<()> {
    if !month.is_ascii() {
        bail!("月份格式无效：{month}");
    }
    if month.len() == 7 && month.as_bytes()[4] == b'-' && month[..4].parse::<u32>().is_ok() {
        let mo = month[5..].parse::<u32>().unwrap_or(0);
        if (1..=12).contains(&mo) {
            return Ok(());
        }
    }
    bail!("月份格式无效：{month}")
}

/// 判定是否 CJK 字符（表意文字主区、扩展 A、兼容表意、扩展 B~F）。
/// 这些字符会被 unicode61 视为连续串的一部分，需要展开为单字。
fn is_cjk_char(c: char) -> bool {
    matches!(
        c as u32,
        0x3400..=0x4DBF | 0x4E00..=0x9FFF | 0xF900..=0xFAFF | 0x20000..=0x2FA1F
    )
}

/// 连续 CJK 字符之间插入空格，使 FTS5 unicode61 按单字建索引。
/// 非 CJK 字符（英文/数字/标点）原样保留，由 tokenizer 自行分词。
pub fn cjk_expand_str(s: &str) -> String {
    let mut out = String::with_capacity(s.len() + s.chars().count() / 2);
    let mut prev_cjk = false;
    for c in s.chars() {
        let is_cjk = is_cjk_char(c);
        if is_cjk && prev_cjk {
            out.push(' ');
        }
        out.push(c);
        prev_cjk = is_cjk;
    }
    out
}

/// 注册 FTS 索引所需的 UDF（每个连接注册一次，必须在迁移/触发器执行前完成）
fn register_functions(conn: &Connection) -> Result<()> {
    conn.create_scalar_function(
        "cjk_expand",
        1,
        FunctionFlags::SQLITE_UTF8 | FunctionFlags::SQLITE_DETERMINISTIC,
        |ctx| Ok(cjk_expand_str(&ctx.get::<String>(0)?)),
    )?;
    Ok(())
}

/// 空白分隔段内的一个子串 → FTS5 表达式片段：
/// CJK 子串展开为单字短语（"超 时"），非 CJK 子串为转义后的前缀词（"API"*）。
fn push_query_part(out: &mut String, part: &mut String, is_cjk: bool) {
    if part.is_empty() {
        return;
    }
    // 多个片段间以空格分隔（FTS5 中相邻 token 为隐式 AND）
    if !out.is_empty() {
        out.push(' ');
    }
    if is_cjk {
        out.push('"');
        out.push_str(&cjk_expand_str(part));
        out.push('"');
    } else {
        // 双引号转义为 ""，并用引号包裹整词，规避 FTS5 特殊语法（AND/OR/NOT/括号等）注入
        out.push('"');
        out.push_str(&part.replace('"', "\"\""));
        out.push_str("\"*");
    }
    part.clear();
}

/// 构造 FTS5 MATCH 表达式（与 cjk_expand 单字索引配套）：
/// 1. 按空白分词；
/// 2. 每段内的连续 CJK 字符展开为单字短语，保证中文任意子串（词中缀）可命中；
/// 3. 非 CJK 串作为带引号的前缀词，支持英文/数字前缀匹配；
/// 4. 多个片段间以空格连接（FTS5 默认 AND 语义）。
pub fn build_fts_query(input: &str) -> String {
    let mut parts: Vec<String> = Vec::new();
    for seg in input.split_whitespace() {
        let mut expr = String::new();
        let mut part = String::new();
        let mut part_is_cjk: Option<bool> = None;
        for c in seg.chars() {
            let is_cjk = is_cjk_char(c);
            if let Some(prev) = part_is_cjk {
                if prev != is_cjk {
                    push_query_part(&mut expr, &mut part, prev);
                }
            }
            part_is_cjk = Some(is_cjk);
            part.push(c);
        }
        if let Some(prev) = part_is_cjk {
            push_query_part(&mut expr, &mut part, prev);
        }
        if !expr.is_empty() {
            parts.push(expr);
        }
    }
    parts.join(" ")
}

fn weekday_cn(d: NaiveDate) -> &'static str {
    const W: [&str; 7] = ["周一", "周二", "周三", "周四", "周五", "周六", "周日"];
    W[d.weekday().num_days_from_monday() as usize]
}

fn fmt_date_cn(d: NaiveDate) -> String {
    format!("{}（{}）", d.format("%Y-%m-%d"), weekday_cn(d))
}

/// 标题中的换行与 Markdown 符号会破坏文档结构，做安全处理
fn sanitize_title(title: &str) -> String {
    let t = title.replace(['\n', '\r'], " ").trim().to_string();
    if t.is_empty() {
        "（无标题）".to_string()
    } else {
        t
    }
}

fn build_markdown(
    kind: &str,
    from: Option<NaiveDate>,
    to: Option<NaiveDate>,
    records: &[WorkRecord],
) -> Result<String> {
    let mut out = String::new();
    let heading = match kind {
        "daily" => format!("# 工作日报 · {}", fmt_date_cn(from.unwrap_or_default())),
        "weekly" => format!(
            "# 工作周报 · {} ~ {}",
            fmt_date_cn(from.unwrap_or_default()),
            fmt_date_cn(to.unwrap_or_default())
        ),
        "monthly" => {
            let d = from.unwrap_or_default();
            format!("# 工作月报 · {}年{}月", d.year(), d.month())
        }
        _ => "# 工作记录总览".to_string(),
    };
    let completed = records.iter().filter(|r| r.status == "completed").count();
    out.push_str(&heading);
    out.push('\n');
    out.push_str(&format!(
        "> 生成时间：{} · 共 {} 条 · 已完成 {}\n",
        now_str(),
        records.len(),
        completed
    ));
    if records.is_empty() {
        out.push_str("\n（该范围内暂无记录）\n");
        return Ok(out);
    }
    out.push_str("\n---\n");

    let mut last_date = String::new();
    let mut idx = 0usize;
    for r in records {
        if kind != "daily" && r.record_date != last_date {
            last_date = r.record_date.clone();
            let d = NaiveDate::parse_from_str(&last_date, "%Y-%m-%d").unwrap_or_default();
            out.push_str(&format!("\n## {}\n", fmt_date_cn(d)));
        }
        idx += 1;
        out.push_str(&format!("\n### {}. {}\n", idx, sanitize_title(&r.title)));
        out.push_str(if r.status == "completed" {
            "状态：✅ 已完成\n"
        } else {
            "状态：⏳ 待完成\n"
        });
        let tags = split_tags(&r.tags);
        if !tags.is_empty() {
            let joined = tags.iter().map(|t| format!("`{t}`")).collect::<Vec<_>>().join(" ");
            out.push_str(&format!("标签：{joined}\n"));
        }
        let content = r.content.trim_end();
        if !content.is_empty() {
            out.push_str(&format!("\n{content}\n"));
        }
        out.push_str("\n---\n");
    }
    Ok(out)
}
```

```ts
export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));

/** 转义正则特殊字符（用户查询词可能包含） */
function escapeRegExp(s: string): string {
  return s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
}

/** 首个命中词在文本中的位置（无命中返回 -1） */
function firstHitIndex(text: string, terms: string[]): number {
  let idx = -1;
  for (const t of terms) {
    const i = text.indexOf(t);
    if (i >= 0 && (idx < 0 || i < idx)) idx = i;
  }
  return idx;
}

/**
 * 按命中词把文本切为片段列表 [{ text, hit }]。
 * 纯文本渲染（模板插值 + <mark>），不经过 v-html，规避 XSS；
 * 词按长度降序优先匹配，避免短词先截断长词。
 */
export function splitByTerms(
  text: string,
  terms: string[],
): { text: string; hit: boolean }[] {
  if (terms.length === 0) return [{ text, hit: false }];
  const sorted = [...terms].sort((a, b) => b.length - a.length);
  const re = new RegExp(sorted.map(escapeRegExp).join("|"), "g");
  const out: { text: string; hit: boolean }[] = [];
  let last = 0;
  for (const m of text.matchAll(re)) {
    const idx = m.index ?? 0;
    if (idx > last) out.push({ text: text.slice(last, idx), hit: false });
    out.push({ text: m[0], hit: true });
    last = idx + m[0].length;
  }
  if (last < text.length) out.push({ text: text.slice(last), hit: false });
  return out;
}

/** 内容摘要：截取首个命中词前后各 radius 字符（无命中时取开头） */
export function snippetAroundTerm(text: string, terms: string[], radius = 40): string {
  const idx = firstHitIndex(text, terms);
  if (idx < 0) {
    return text.length > radius * 2 ? `${text.slice(0, radius * 2)}…` : text;
  }
  const start = Math.max(0, idx - radius);
  const end = Math.min(text.length, idx + radius);
  return `${start > 0 ? "…" : ""}${text.slice(start, end)}${end < text.length ? "…" : ""}`;
}

/** 拆分逗号分隔的标签字符串为数组 */
export function splitTags(tags: string): string[] {
  return tags
    .split(/[,，;；]/)
    .map((t) => t.trim())
    .filter((t) => t.length > 0);
}

/** 拼接标签数组为逗号分隔字符串（去重） */
export function joinTags(tags: string[]): string {
  return [...new Set(tags.map((t) => t.trim()).filter((t) => t.length > 0))].join(",");
}

  if (e instanceof Error) return e.message;
```

#### `src/composables/useAutoSave.ts`

```ts
/**
 * 编辑防抖自动保存。
 * markDirty：内容变更后调用，500ms 防抖后落库；
 * flush：立即保存（手动保存按钮 / 切换记录前 / 组件卸载前兜底）；
 * 保存失败不吞错：通过 onError 回调由界面 toast 提示。
 */
import { onBeforeUnmount, ref } from "vue";

export interface AutoSaveOptions {
  /** 执行保存（失败抛异常） */
  save: () => Promise<unknown>;
  /** 防抖延迟 ms，默认 500 */
  delay?: number;
  /** 保存失败回调 */
  onError?: (e: unknown) => void;
}

export function useAutoSave(options: AutoSaveOptions) {
  const delay = options.delay ?? 500;
  /** 有未落盘的修改 */
  const pending = ref(false);
  /** 正在保存中 */
  const saving = ref(false);
  let dirty = false;
  let timer: ReturnType<typeof setTimeout> | undefined;

  function markDirty(): void {
    dirty = true;
    pending.value = true;
    if (timer !== undefined) clearTimeout(timer);
    timer = setTimeout(() => {
      void flush();
    }, delay);
  }

  /** 立即保存；返回是否成功。无未落盘内容时直接返回 true。 */
  async function flush(): Promise<boolean> {
    if (timer !== undefined) {
      clearTimeout(timer);
      timer = undefined;
    }
    if (!dirty) return true;
    saving.value = true;
    try {
      await options.save();
      dirty = false;
      pending.value = false;
      return true;
    } catch (e) {
      // 保存失败保持 dirty 状态，等待下次触发重试，不静默丢失
      options.onError?.(e);
      return false;
    } finally {
      saving.value = false;
    }
  }

  // 组件卸载前兜底保存最后内容
  onBeforeUnmount(() => {
    void flush();
  });

  return { pending, saving, markDirty, flush };
}
```

```ts
/**
 * 全局快捷键（macOS 同时兼容 Cmd）：
 * - Ctrl+N：新建工作记录
 * - Ctrl+F：聚焦搜索输入框
 * - Ctrl+S：手动保存（自动保存的兜底）
 */
import { onMounted, onUnmounted } from "vue";

export interface HotkeyHandlers {
  onNew?: () => void;
  onSearch?: () => void;
  onSave?: () => void;
}

export function useHotkeys(handlers: HotkeyHandlers): void {
  const onKey = (e: KeyboardEvent): void => {
    if (!(e.ctrlKey || e.metaKey) || e.altKey) return;
    const k = e.key.toLowerCase();
    if (k === "n") {
      e.preventDefault();
      handlers.onNew?.();
    } else if (k === "f") {
      e.preventDefault();
      handlers.onSearch?.();
    } else if (k === "s") {
      e.preventDefault();
      handlers.onSave?.();
    }
  };
  onMounted(() => window.addEventListener("keydown", onKey));
  onUnmounted(() => window.removeEventListener("keydown", onKey));
}
```

```vue
    loading.value = false;
```

```vue
 * - 停止输入 500ms 自动保存（useAutoSave），保存按钮与 Ctrl+S 手动兜底

import { Loader2, NotebookPen, Plus, Save, Trash2, X } from "@lucide/vue";

import { Badge } from "@/components/ui/badge";
import { Button } from "@/components/ui/button";
import { Input } from "@/components/ui/input";
import { Label } from "@/components/ui/label";
import { Switch } from "@/components/ui/switch";
import { Textarea } from "@/components/ui/textarea";
import { toast } from "@/components/ui/toast";
import * as api from "@/api/records";
import { useAutoSave } from "@/composables/useAutoSave";
import { useAppStore } from "@/stores/app";
import { errMsg, joinTags, splitTags } from "@/lib/utils";
import { fmtTime } from "@/composables/useDate";
import type { WorkRecord } from "@/types/work-record";

const props = defineProps<{ record: WorkRecord | null }>();

const emit = defineEmits<{
  saved: [r: WorkRecord];
  deleted: [];
  create: [];
}>();

const store = useAppStore();

const form = reactive({
  title: "",
  content: "",
  status: "pending" as "pending" | "completed",
  tags: [] as string[],
});
const tagInput = ref("");
const deleting = ref(false);

/** 当前正在编辑的记录 id（保存时使用，切换记录后仍能落盘到正确记录） */
let editingId: number | null = null;
/** 从 props 同步表单时置位，抑制变更监听 */
let syncing = false;

const autosave = useAutoSave({
  save: async () => {
    if (editingId == null) return;
    const updated = await api.updateRecord(
      editingId,
      form.title,
      form.content,
      form.status,
      joinTags(form.tags),
    );
    emit("saved", updated);
  },
  onError: (e) => {
    toast({ title: "自动保存失败", description: errMsg(e), variant: "destructive" });
  },
});

// 切换记录：先保存上一条，再同步新记录表单
watch(
  () => props.record?.id,
  async (id, oldId) => {
    if (oldId != null && oldId !== id) await autosave.flush();
    syncing = true;
    form.title = props.record?.title ?? "";
    form.content = props.record?.content ?? "";
    form.status = props.record?.status ?? "pending";
    form.tags = splitTags(props.record?.tags ?? "");
    tagInput.value = "";
    editingId = id ?? null;
    syncing = false;
  },
  { immediate: true },
);

// 表单变更 → 触发防抖自动保存
watch(
  form,
  () => {
    if (!syncing && props.record) autosave.markDirty();
  },
  { deep: true },
);

/** 手动保存（兜底） */
async function manualSave(): Promise<void> {
  if (!props.record) return;
  const ok = await autosave.flush();
  if (ok) {
    toast({
      title: "已保存",
      description: `保存于 ${new Date().toLocaleTimeString("zh-CN", {
        hour: "2-digit",
        minute: "2-digit",
      })}`,
    });
  }
}

/** 软删除（确认后执行） */
async function confirmDelete(): Promise<void> {
  if (!props.record) return;
  deleting.value = true;
  try {
    await api.softDelete(props.record.id);
    emit("deleted");
    toast({ title: "已移入回收站", description: "可在回收站页面恢复" });
  } catch (e) {
    toast({ title: "删除失败", description: errMsg(e), variant: "destructive" });
  } finally {
    deleting.value = false;
  }
}

// ---- 标签编辑 ----

function addTag(): void {
  const t = tagInput.value.trim().replace(/[,，;；]/g, "");
  if (!t) return;
  if (t.length > 50) {
    toast({ title: "标签过长", description: "单个标签不能超过 50 个字符", variant: "destructive" });
    return;
  }
  if (!form.tags.includes(t)) form.tags.push(t);
  tagInput.value = "";
}

function removeTag(t: string): void {
  form.tags = form.tags.filter((x) => x !== t);
}

function onTagKeydown(e: KeyboardEvent): void {
  if (e.key === "Enter" || e.key === ",") {
    e.preventDefault();
    addTag();
  } else if (e.key === "Backspace" && tagInput.value === "" && form.tags.length > 0) {
    form.tags = form.tags.slice(0, -1);
  }
}

function toggleStatus(checked: boolean): void {
  form.status = checked ? "completed" : "pending"; // watch 触发自动保存
}

// 暴露给父组件：手动保存（Ctrl+S）与切页前兜底
defineExpose({
  flush: () => autosave.flush(),
});
</script>
```

## ⑤ sqlite 路径与备份说明

**数据库位置**（Tauri 应用数据目录下的 `work-journal.db`，应用内「设置」页会显示实际路径）：

| 平台 | 路径 |
|---|---|
| macOS | `~/Library/Application Support/com.workjournal.app/work-journal.db` |
| Windows | `C:\Users\<用户>\AppData\Roaming\com.workjournal.app\work-journal.db` |
| Linux | `~/.local/share/com.workjournal.app/work-journal.db` |

**备份与恢复说明**：

1. **数据库启用 WAL 模式**（journal_mode=WAL），数据会先写入 `work-journal.db-wal` 再合并。**不要直接拷贝正在运行应用的 .db 文件**（可能丢失 WAL 中未合并的数据）。
2. **正确备份方式**：应用内「设置 → 备份数据库」——使用 SQLite 在线备份 API（`rusqlite::backup`）生成一致性快照，正在使用时也能安全复制，产物为 `工作日志备份-<时间戳>.db`。
3. **恢复**：应用内「设置 → 从备份恢复」选择 .db 文件。恢复前应用会**先自动把当前数据备份**到应用数据目录（`恢复前自动备份-<时间戳>.db`），误操作可挽回；恢复后自动重建 FTS 索引并全量刷新界面。
4. **恢复校验**：所选文件必须是有效 SQLite 且含 `records` 表，否则拒绝并报错（不会用无效文件覆盖现有数据）。
5. **版本迁移**：schema 版本记录在 `PRAGMA user_version`，升级时按版本递增执行迁移脚本（每版本一个事务），历史数据不丢失；已发布版本脚本永不修改，只追加新版本。

## 风险提示

1. **FTS5 中文单字索引的空间开销**：连续 CJK 展开为单字后索引体积约为普通分词数倍，对超大文本量（单条 10 万字 × 数千条）的库体积与写入耗时未做压测，建议大数据量场景实测后评估是否需要限制索引列（当前 title/content/tags 全索引）。
2. **搜索召回精度**：单字短语匹配是「子串命中」而非语义分词，中文查询如「时超」（倒序）不会命中「超时」，但任意顺序子串均可命中——符合 PRD 的任意子串定位目标；英文部分仅前缀匹配（`"API"*`），不支持下缀/中缀匹配。
3. **Windows 实机未验证**：`windows_subsystem = "windows"`、NSIS 打包、中文路径均未经 Windows 实机测试；首次在 Windows 打包需安装 WebView2 构建依赖。
4. **恢复中的 WAL 中间态**：恢复用备份 API 覆盖库文件，期间应用若被强杀理论上有极小概率损坏主库——已有「恢复前自动备份」兜底，若发生可用应用数据目录下 `恢复前自动备份-*.db` 挽回。
5. **CSP 配置为 null**：本地无网络应用风险低，但若未来引入远程内容（如内嵌外部图片链接），需补充 CSP 配置。
6. **主题偏好存 localStorage**：仅 UI 偏好（非业务数据），清空 WebView 数据会重置主题但不影响 SQLite 中的记录数据。
7. **待人工复核**：ui 标准件除 3.6 列出的 3 处外为 CLI 生成件未逐行审查；`db.rs` 触发器依赖 UDF 注册顺序（open 时先 register 后 migrate），后续加迁移版本时须保持该顺序不变。
